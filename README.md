# 🛡️ Phishing Awareness Analysis

A Python-based cybersecurity tool that helps users identify potential phishing emails and messages by detecting suspicious keywords and common social engineering tactics.

## 📌 Overview

Phishing attacks are one of the most common cyber threats used to steal sensitive information such as passwords, banking details, and personal data.

This project analyzes user-provided text and highlights possible phishing indicators, providing a simple risk assessment report.

## ✨ Features

* Detects common phishing keywords
* Identifies suspicious message patterns
* Generates a risk level assessment
* Displays detailed analysis reports
* Beginner-friendly cybersecurity project
* Command-line interface (CLI)

## 🛠️ Technologies Used

* Python 3
* Object-Oriented Programming (OOP)
* String Processing
* Cybersecurity Concepts

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Soheetpatil/Phishing-Awareness-Analysis.git
```

Move into the project directory:

```bash
cd Phishing-Awareness-Analysis
```

## ▶️ Run the Project

```bash
python phishing_awareness_quiz.py
```

## 💻 Example Usage

Input:

```text
Your bank account will be suspended. Verify your account immediately.
```

Output:

```text
⚠ Potential Phishing Detected!

Red Flags Found:
• bank account
• suspended

Risk Level: HIGH
Recommendation: Do NOT click links or share personal information.
```
